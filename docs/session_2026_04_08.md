# Design Session: April 8, 2026 — Key Insights

## Resolved Today

### 1. Fibonacci is out
Imposed, not emergent. The mechanism produces linear context growth. Don't impose what doesn't emerge.

### 2. Option B confirmed — path IS context
Each node stores only its contribution. Full context = path from root. Spectrum stays Vec<u8>.

### 3. Radiation = self-advertisement, Buffers = connectors
Nodes broadcast their spectrum ("this is me"). No space exists — just buffers with unprocessed deposits. A buffer from one source = child. A buffer from multiple sources = lateral binding. Tree becomes DAG naturally.

### 4. Agent as lateral connector
The agent (Claude) perceives patterns across branches and writes discoveries back. The trie stays a tree. Concepts form through the observe-write-back loop.

### 5. Classify fix — crystallized nodes return Different, never Unknown
Only Learning nodes say Unknown. This enables branching. Two-line change, biggest impact.

### 6. Fair routing — try all subtrees before creating sibling
route() returns bool. If a subtree can't handle the token, try the next. Prevents first-child monopoly.

### 7. The trie is a familiarity detector (layer 1)
It answers "have I seen this before?" not "what was it about?" Content store (layer 2) maps recognition signatures to actual content. Like hippocampus (index) pointing to cortex (content).

### 8. Delta encoding
Feed changes not values. Same principle as video experiments. Produces meaningful depth on English text.

## Unsolved / Parked

### Lateral buffer formation
How does the first connection between unrelated nodes form without an external agent? Parked — the agent loop works for now.

### Append upward
"You can only add, but we're not saying where." Growing the tree upward — adding a new root above the current one. Not explored yet.

## Key Insights for Next Session

### Learning curriculum matters
Children learn alphabet → syllables → words → sentences. Each layer crystallizes deeply before the next starts. We've been feeding complex prose before the trie learned basic patterns. The universe built hydrogen before planets.

**Next experiment:** Wipe the trie. Feed in curriculum order. See if the structure is qualitatively different.

### Multi-sensory binding
Children learn through simultaneous audio + visual + tactile input. Multiple streams create multiple branches pointing to the same concept through temporal co-occurrence. This is the lateral binding problem solved biologically.

**Implication:** The trie might need multiple simultaneous input streams, not just one text stream. Different modalities create different branches that bind through timing.

### Healthy skepticism
"Any rules can give you some kind of structure." The test isn't whether structure emerges — it's whether the structure helps you do something you couldn't do before. We haven't fully proven that yet. The branching works but currently separates character patterns, not semantic topics.
